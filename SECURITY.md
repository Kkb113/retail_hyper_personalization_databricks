# Security policy

This public repository must contain synthetic POC data only. Do not commit
customer data, credentials, Databricks tokens, service-principal secrets, raw
subscription or tenant IDs, connection strings, or private endpoints.

Report a vulnerability privately through GitHub's **Report a vulnerability**
security-advisory flow for this repository. Do not disclose exploitable details
in a public issue.

The POC is not approved for production data or production traffic.
